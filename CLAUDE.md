# Claude Code Context

This project is a learning sandbox for experimenting with Claude Code.

## Project Layout

- `src/` — Python source modules
- `tests/` — pytest tests
- `docs/` — markdown notes and experiment logs
- `scripts/` — utility/automation scripts
- `data/` — sample input/output data
- `experiments/` — scratch work and one-off experiments

## Conventions

- Run tests with `pytest`
- Keep experiments isolated in `experiments/` so `src/` stays clean
