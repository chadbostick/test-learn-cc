# Notes

General notes about Claude Code features, tips, and observations.

## Useful Commands

- `/help` — show available slash commands
- `/clear` — clear conversation context
- `/compact` — summarize context to save tokens
- `/cost` — show token usage

## Tips

- Use `!` prefix to run shell commands inline (e.g. `! git status`)
- CLAUDE.md in project root is auto-loaded as context
